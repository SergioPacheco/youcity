# YouCity Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a static English blog at `/blog` and `/blog/<slug>` with safe local Markdown, two complete examples, ten drafts, SEO metadata, sitemap integration, documentation, and validation.

**Architecture:** Versioned Markdown under `content/blog/` is parsed during the existing static build. A small build-only line/state renderer emits safe HTML into shared templates. Blog documents use dedicated CSS and do not load the interactive app, player, radio, map, catalog, or analytics bootstrap.

**Tech Stack:** Existing Node.js/CommonJS build scripts, vanilla HTML/CSS, catalog JSON, Node assertion tests, no new npm dependency.

**Spec:** `docs/superpowers/specs/2026-09-20-blog-design.md`

## Global constraints

- Preserve the current interactive app, city generation, consent/legal pages, Cloudflare files, and base-path behavior.
- Do not add a framework, database, runtime dependency, client-side blog bootstrap, comments, login, search, pagination, player, radio, map, or sharing library.
- The renderer must reject raw HTML and unsafe URLs; metadata and JSON-LD must be escaped for their output context.
- Only non-draft, non-future articles are public, listed, linked, and included in the sitemap.
- Do not deploy or push automatically.

## Review focus

- Unsafe Markdown and protocols fail or remain escaped — covered by Task 1 tests.
- Draft/future articles and draft relations never leak — covered by Task 2 tests.
- `SEO_BASE_PATH=/youcity` is applied once to every generated URL — covered by Tasks 4 and 7.
- Blog pages remain complete with JavaScript disabled and contain no app bootstrap — covered by Tasks 4 and 7.
- Invalid slugs, dates, cities, images, or relations fail with a source filename — covered by Tasks 1 and 2.
